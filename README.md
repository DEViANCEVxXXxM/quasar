# Quasar

A simple black hole visualization that runs in your browser.

## What it is
Quasar is a single web page that shows a black hole and some related space effects, such as light bending and the event horizon.

## How to use
0. [Try on Pages](https://deviancevxxxxm.github.io/quasar/)
   
   or
   
2. Download or clone this repository.
3. Open `index.html` in a web browser.
4. Drag to rotate the view.
5. Scroll to zoom in and out.

No install or server is needed.

## Files
- `index.html` — the main page.
